# Roadmap

## v0.1 milestones

- [x] Project foundation and reusable package layout.
- [x] Domain contracts and stable enums.
- [x] SSRF-resistant networking boundary.
- [x] Scanner orchestration and rule protocol.
- [x] Initial passive transport and HTTP security-header checks (Phase 5A).
- [ ] Additional passive checks for cookies, security.txt, mixed content, and disclosure (Phase 5B).
- [ ] Deterministic scoring and coverage.
- [ ] CLI presentation and JSON/HTML reports.
- [ ] REST API.
- [ ] CyberNet-branded web interface.
- [ ] Deployment hardening and release validation.

No unchecked milestone is implemented by the current repository state. Phase 5A contains no
cookie, security.txt, mixed-content, disclosure, scoring, reporting, interface, or persistence
features.
